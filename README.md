# ZPlusBank Old Domain Redirect 🌐

This repository exists solely to handle the automatic redirection of the legacy domain `https://github.io` to our new, official website.

## 🚀 New Destination
Our website has permanently moved to:
👉 **[https://zplus.codes](https://zplus.codes)**

---

## 🛠️ How It Works
The redirection is handled entirely client-side using a clean, lightweight static setup in `index.html` via:
1. **HTML Meta Refresh:** The primary method for immediate browser redirection.
2. **JavaScript Fallback:** Ensures immediate navigation if the meta tag is bypassed.
3. **Canonical Link:** Signals to search engines (like Google) that SEO authority should transfer to the new domain.
